# 上級作品「こうもり」の追加 — 2026-09-25

全61作品。こうもりは難易度3（上級）、どうぶつ、全9工程。
左右の二重の羽を別々に折り、別の線で折り返してから中央の顔だけを折るため、
層と折り線の選択が必要な作品として上級に分類した。

## 折り線と形状の自己照合

元紙は半径1のひし形、面積2。`flatSequence` を使い、既存エンジンは変更していない。

- 上の角を折る線 `H=.43`。図のパネル3の三角の高さに対する破線は約.44、
  パネル4の台形の高さからは約.43。下端を少し越える先は `2H-1=-.14`。
- 羽を折り下げる線は `(0,H)` から `(±H,0)` への45度線。
- 折り返し線は `(±H,0)` から `(0,Q)`、`Q=.29`。
  パネル5の頂点から破線の中央までの差は約.14。H/Qは目印のない実測比率。
- 顔の折り線も `y=Q`。`exceptFold:[4,5]` で折り返した翼を除外する。
  最終曲げは16度（参考の「少し後ろに折る」）。
- 平面完成で翼先 `(±.9585,.2136)`、肩 `(±.3987,.4511)`、尾 `(0,-.14)`。
  顔の先 `(0,.15)`。完成図の縦横比は約3.15、最終モデルは約3.18（5%以内）。
- 紙厚の既定値では多層の継ぎ目コピーが最大.00112離れるため、この作品だけ `2e-6` にした。
  最大差は.000224。表示専用の層間隔を追加せず、SVGとWebGLとも色の面が出ることを確認。
