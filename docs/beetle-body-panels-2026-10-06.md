## 不採用の開口候補を再現する診断

`tools/probe-beetle-body.mjs` はモデルファイルを書き換えない作成用の数値実験。中央の4つの内側の点を深さの異なる位置へ動かし、面の寸法を拘束して全体の姿勢を求める。実際の多角形の全頂点間距離を拘束するため、対象外の面を曲げて残差を小さくしない。

```powershell
node --import ./tools/register-typescript.mjs tools/probe-beetle-body.mjs
```

既定値 `--width=.005 --iterations=400` の今回の結果：

| 判定 | 結果 |
|---|---|
| 原紙に対する最大の面寸法誤差 | 2.7502294608350297e-7 |
| 寸法の許容値 | 5e-7（変更なし） |
| 寸法判定 | 成功 |
| 横断する面の交差 | **4445組** |
| 姿勢の整合性 `poseConsistent` | **false** |
| 連続した折る経路 `routeValidated` | **false** |

したがって **不採用**。数値残差が小さくても紙の面が交差する姿勢を作品へ組み込まない。診断は不整合の候補で失敗終了し、連続した経路は一姿勢からは証明できないため常に `routeValidated:false` を返す。交差の検出数に上限を設けない。

その他の私的試算では背中の直線の折り面を反対向きに開く候補も調べた。寸法は保てても白い中央の帯が大きく出て見本の確認ができず、不採用。比較用ソースは撤去した。無視対象の `tools/.zu` の試算を完成モデルや正しい折り方として使わない。
