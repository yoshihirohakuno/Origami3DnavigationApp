# カブトムシ：背中の折り面による曲率と接地姿勢の比較

## 状態

カブトムシ → バラ → ドラゴンを一作品ずつ完成させる。完成は **0/3**。公開81作品・名人2作品は変更していない。バラ・ドラゴンは未着手。難易度は実際の折り方に合わせる。

今回の `curved-pose` は未完成の比較試作。背中中央に裏面の見える隙間が残り、見本の閉じた背中とは一致していない。丸み、接続、接地の検査が通っても、袋の開口を再現できたとは扱わない。

## 実装

- `src/experiments/beetleCurvedBodyStudy.ts`: 既存の四つの胴体面に各5本、計20本の実際の材料の折り線を追加。面幅の15/30/45/60/75%で各8°曲げる。付け根から外へ順に折り、次に曲げる部分は平面のまま保持する。131操作・743頂点・888面。
- `src/experiments/beetleCurvedPoseStudy.ts`: 新しい背中に既存の角、肩、膝、足先、角の先端を接続。144操作・1062頂点・1200面。六脚は折り線と長さから求めた曲げ角で `z=-.1` に接地する。
- `src/experiments/beetlePoseStudy.ts`: 仕上げを `createBeetleSupportPose` として再利用可能にした。従来の124操作の試作とその公開エクスポートは保持する。
- `src/experiments/beetleStudyMain.tsx`: 開発専用の比較経路を追加。公開一覧、通常UI、既存作品の紙の動作は変更していない。

折り線は `foldSpatialFlap` で原紙の多角形を細分化し、実際の軸回転として動く。レンダリングだけで膨らませたり、頂点の目標位置へ補間したり、面ごとに塗り直したりしていない。前回の `body-mesh` の細分化は別の試作として保持し、今回の動作の成功と混同しない。

## 確認

`tests/beetle-curved-back.test.mjs` の6件と、全456件のテストが成功。`npm run build` 成功。`npm run lint` は既存の6警告のみ。ビルドの500KB超警告も既存のもの。

- 144操作を1/8工程間隔の1153姿勢で検査。原紙の面積4、各面の頂点間距離を保持する。前111操作は従来の動作と一致する。
- 材料の内側の辺はすべて二面が共有し、自由な境界は原紙の外周だけ。面の隣接グラフは一つに接続し、未分割の辺に途中頂点を残していない。共有辺の端点は同じ頂点IDを使う。
- 背中を曲げる間は1/16工程間隔で六脚と二本の角の先端、背中の固定点が動かない。
- 111から144までの265姿勢で横断交差を検査し、検出なし。これはサンプル検査であり、全連続時間の証明や実物の折り方の検証ではない。
- 六つの足が接地し、紙が支持面より下へ出ない。角先の仕上げと最後の全体回転でも接地を保持する。
- 公開一覧へ未登録、未完成の注意書き、単独折り工程、統一した原紙の表裏を確認。

本番ビルドのJS/CSSは前回と同じ出力ハッシュで、この開発専用経路は本番へ入っていない。

ブラウザーでは111.17の途中姿勢を表示し、単独再生が112.00で停止することを確認。最終144操作の正面表示では、丸い折り面と中央の白い隙間を確認した。スクリーンショットはローカルの `tools/.zu/beetle-curved-pose-2026-10-06.png` に保存する（Git対象外）。

## 未解決と不採用案

内側の八つの材料点がまだ背骨の同じ位置に重なる。今回は従来の四枚のページ状の近似へ曲率を付けたものであり、実際の袋を開いたことにはならない。背中中央の裏面の隙間も残る。

原作者 [Jo Nakashima の Hercules Beetle 動画](https://www.youtube.com/watch?v=F-zQOAwSuHg) の25:28と26:08付近を比較したが、全材料と層順の追跡、実物での折りの照合はまだできていない。

平らな初期姿勢から材料点の位置を求め直す別の数値候補は、面寸法の最大誤差3.8958792019511135e-7でも横断交差11437組を検出したため不採用。`tools/.zu/probe-beetle-continuation.mjs` という診断名でも、連続した折り経路を成立させたものではない。許容誤差を緩めたり交差する姿勢を採用したりしない。

3. 連続動作、紙の接続・寸法・交差、見本と最終形・表裏の一致を確認してから公開する。
4. カブトムシの完成後にバラ、ドラゴンへ進む。
