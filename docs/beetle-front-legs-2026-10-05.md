# カブトムシの前脚の立体折り

公開81作品・名人2、依頼のカブトムシ→バラ→ドラゴンは完成0/3のまま。
部分基本形の構造試作を101操作から103操作へ更新した。404頂点・483面。

## 修正した部分

旧試作では6本とも、脚の中心線の72%の位置で先を下げていた。
前脚は肩から持ち上げ、その先を下げる2段階が必要で、この形を作れていなかった。

左右の前脚について、自由に折れる脚の根元側を35°持ち上げる操作を一つずつ追加した。
持ち上げた部分の長さの1/3に実際の3D折り線を入れ、そこから65°下へ曲げる。
左右の持ち上げ、左右の折り下げは、それぞれ別工程として案内する。
残り4脚の試作の折りは今回変更していない。

根元は、名目上の中心線と脚先を結ぶ線の20%の位置。
これは自由な前脚の材料だけを選ぶための試作位置であり、実物の最終の肩の位置を確定したものではない。
背中が曲がった後に0〜15%の位置で折る案は、折る材料が非平面になるため採用しなかった。
非平面判定を緩めず、実際の平面の脚とその折り線を `foldSpatialFlap` で扱う。

折り下げ100°の比較案は、94.875の姿勢で面286と354の交差が検出され、不採用。
採用した65°では、今回検査した全姿勢で横断的な面の交差はなかった。
色の変更、座標のモーフィング、紙の切断で形を整えていない。

## 照合・検査

[Jo Nakashimaの動画](https://www.youtube.com/watch?v=F-zQOAwSuHg)の22:09、23:39、25:09、26:09、27:09、27:39、28:09、28:39の選択した姿勢をブラウザーで確認した。
背中の層を開く立体化と、その後の角の付け根のつまみ折りは現在の試作と異なる。
動画全体の全操作を閲覧・再現済みとはしない。

追加した前脚の検査は、肩より関節が高く、脚先が関節から下がること、
実際の関節が折り線上に留まること、関節の角度と脚の長さ、左右対称を確認する。
既存の先端分離の検査にも左右の肩の操作を追加した。
全103操作の1649姿勢で面内の全点間距離、825姿勢で継ぎ目、正方形を開く以降の497姿勢で横断的な面の交差を検査する。
試作固有の8テストは成功。
全394テストとbuildも成功。lintは既存6警告で、新規警告なし。
ブラウザーで前脚を持ち上げた状態と折り下げた状態を横・斜めから確認し、試作の最終状態も表示した。
94からの単独再生が95.00で停止し、左右の折り下げを一度に進めないことを確認した。

## 次に必要なこと

1. 角の半折りを、実物の付け根のつまみ折りへ置き換える。
   現在の全中心線による半折りは、付け根周囲の層も組み替える。検査成功を実物の再現と同一視しない。
2. 背中の層を開いて丸みを作り、盾になる広い層とその段折りを実装する。
   現在の左右20°の傾斜だけでは、この立体化を再現できていない。
3. 肩と残り4脚の位置、完成時の表裏と輪郭を照合する。
4. カブトムシの完成を確認して公開してから、バラ、ドラゴンへ進む。
