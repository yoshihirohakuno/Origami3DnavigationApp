# カブトムシの層と前脚の補正（未完成）

公開81作品・名人2、依頼されたカブトムシ・バラ・ドラゴンは完成0/3。
カブトムシを完成させてから次へ進める。今回の試作は114操作・407頂点・498面で、一覧には登録していない。

## 修正

- 角を中心へ折った後に、平らな側を上にする全体の裏返しを追加した。基本形の生成を `beetlePetalBase.ts` に分離し、旧65操作版の経路は維持した。
- 内側の角を出す前に、重なった外側の二つの半面をもとの材料の辺で表へ返す。4区画で計8操作。小さい角だけを反転する旧経路では、この層の反転が抜けていた。
- 左右の前脚の広い自由な層を、脚の中心線で内側へ折り込む2操作を追加した。閉じた背中の先・他の8先端・肩の4点を動かさない。反対側を選ぶ案は背中まで動かすため不採用。
- 試作だけ描画の連続平面を同じ層にまとめた。同じ紙の材料上で長さのある辺を共有し、向きと物理的平面も一致する場合に限る。点で触れる面・別紙・裏返した層は結合しない。T字の細分割にも対応。既存作品の既定描画と物理座標は変更しない。
- 三角形の数ではなく連続した平面ごとに間隔を与えるため、描画間隔を4e-5にした。細い表裏の縞が出ないことをブラウザーで確認した。

## 次の実装

4. 残り4脚の付け根と、完成形の表裏を確認する。白面スタートは暫定。
