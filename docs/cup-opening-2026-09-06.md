# コップの開口時の接続修正 — 2026-09-06

ユーザーの横からのスクリーンショットで、口を開くと側面が切り離される問題を確認した。
前の壁と折り込んだ左右の角を手前へ、後ろの壁を奥へ、同じ底辺軸で独立回転していたため、
本来同じ紙の点だった側面の頂点が最大0.2494557離れていた(展開時の紙の対角線は2)。
以前の「各面の辺長が変わらない」テストでは、この接続不良を検出できなかった。

最初の5工程の折り方と前後のフタの順は保ち、6工程目の開き方を変更した。
左右が少し内側へ寄り、前後の壁がふくらむ。元の紙の座標が一致する共有点を接続しており、
追加の紙や隙間を隠す面は使っていない。元々別の紙の点が重なっている部分は溶接せず、口を開けられる。

重なる紙は共通のグリッドで細分化し、同じ曲面を参照する。細分化の線は折り線として表示しない。
曲面はサンプル点の補間による近似で、厳密な展開可能曲面・剛体折りの解ではない。
紙厚による重なりと接続の両立にも近似を含む。

検証結果:

- 細分化後も元の正方形の面積は2。内部で片側だけに面がある辺は0。
- 全工程を0.05工程刻みで検証し、紙の共有辺の両端は誤差1e-9未満で一致。
- 完成時の口の中央の前後幅は約0.2034。側面をつないでも開口を維持。
- 同じサンプリングで各小三角形の辺長の相対変化は最大約2.90%。3%を回帰検証の上限とした。
- 正面から白い前フタが見えること、JSONで保存・再読込しても曲面が同じことを検証。
- 曲面用の細分化がSVGのBSP処理を肥大化させないよう、画面のタイルごとに正しい奥行きで分割・整列。
  密な交差面の回帰検証も追加した。
- 全105テスト成功、ビルド成功。lintは従来の警告6件のみ。両監査コマンドを実行した。
- ローカル画面を回転し、開口と側面の接続を確認。

エディタでは曲面のJSONと再生を扱える。曲面作品への折り線追加はまだ対応していないため、
この操作は説明付きで停止する。既存メッシュを捨てて破損させない。
