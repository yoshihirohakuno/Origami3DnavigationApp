# コップの工程ガイド UI 試作

URL: http://127.0.0.1:5173/?model=cup&view=guided

## 目的と範囲

LEGO Builder の公式案内にある「工程ごとの3D表示・回転・拡大」を参考に、実際に折る人のペースで進める案内を試す。
公式資料: https://www.lego.com/en-gb/service/help-topics/article/lego-builder-app-3d-building-instructions
ブランドや画面の複製ではなく、既存の白・淡い緑のデザインと日英併記を維持する。サイト内に参考ブランドの名前は表示しない。

対象は既存のコップ1作品・6工程のみ。作品数、折り方、表裏、紙の形状のデータは変更しない。
公開一覧から「コップで新しい案内を試す」で入れる。従来のコップ画面にも切り替え入口がある。
画面の切り替え・再読み込みでは工程1へ戻る。途中の工程の永続保存はまだ実装していない。

## 実装した体験

- 今の工程を大きく表示し、長い工程一覧を6個の進捗表示へ置き換える。
- 実際の折りデータから折る前・折った後のSVGを生成し、どちらもクリックで3Dへ反映する。
- 再生は約2.6秒で今の工程だけを動かし、その工程の終わりで止まる。
- 「折れた！次へ」だけが確認済み工程を進める。見本の閲覧や再生で確認済み数を増やさない。
- 最後の「できあがり！」で既存の作品記録へ加算する。同じ試作セッション内で戻って再確認しても重複加算しない。
- 前の工程へ戻れる。途中の動きは現在工程専用のスライダーで確認できる。
- 3Dの回転・正面リセット・裏側・拡大縮小、表裏の凡例を表示する。
- スマートフォンでは工程説明を3Dの上にも表示し、次の工程へ進むとそこを見せる。
- prefers-reduced-motion では再生操作で即座に工程の目標姿勢を表示し、確認は利用者に委ねる。

## 検証

新規の5テスト成功。既存のコップとナビゲーションなど8テスト成功（新規の境界テスト1件を含むため重複を除く12件）。
build成功。lintは既存の6警告のみ。
ブラウザーで1・2工程目の再生停止、全6工程の説明と見本、裏側、拡大縮小、従来画面との切り替え、一覧からの入口を確認。
375×812のスマートフォン表示で横方向のあふれがないことと、次の工程で説明と3Dが見えることを確認。
開発中のホット更新で古いPaperSceneのインスタンスに新しい拡大関数がないエラーが1回出た。再読み込み後の拡大縮小で新たなエラーは発生していない。
ブラウザーで実際に完成記録を加算する最終ボタンは押していない。再生と確認の分離は状態テストで検査した。
実物を折りながらの親子による利用確認は未実施。全作品へ展開する前に、読む量・手元と画面の往復・迷う工程を確認する。
