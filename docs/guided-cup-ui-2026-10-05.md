# コップの工程ガイド UI 試作（2026-10-06更新）

URL: http://127.0.0.1:5173/?model=cup&view=guided

## 目的と範囲

LEGO Builder の公式案内にある「工程ごとの3D表示・回転・拡大」を参考に、実際に折る人のペースで進める案内を試す。
公式資料: https://www.lego.com/en-gb/service/help-topics/article/lego-builder-app-3d-building-instructions
ブランドや画面の複製ではなく、既存の白・淡い緑のデザインと日英併記を維持する。サイト内に参考ブランドの名前は表示しない。

対象は既存のコップ1作品・6工程のみ。作品数、折り方、表裏、紙の形状のデータは変更しない。
公開一覧から「コップで新しい案内を試す」で入れる。従来のコップ画面にも切り替え入口がある。
画面の切り替え・再読み込みでは工程1へ戻る。途中の工程の永続保存はまだ実装していない。

## 実装した体験

- 今の工程と番号だけを表示し、全工程一覧を表示しない。
- 折る前・折った後のSVGを「現在の形／次の形」の2枚で表示する。クリックでも途中の折りを通って移動する。
- 「折る動きを見る」で現在の折りを再生し、終わりで停止する。「次の工程へ」で次の折りを再生する。再生中の連打で飛ばさない。
- 従来のナビゲーターと同じ速度（毎秒0.9工程）へ戻し、ゆっくり再生は半分の速度とする。紙の描画を状態更新と同じフレームで行う。
- 3Dのすぐ下に再生・一時停止・続きの再生・再再生・スライダーを配置する。一時停止からの再開で折る前へ戻さない。
- 「戻る」も現在の折りを逆再生する。工程境界の切り替えでは紙の姿勢を保つ。
- 最後の「できた！記録する」で既存の作品記録へ加算する。見本の閲覧・再生だけでは記録せず、同じセッション内で重複加算しない。
- 短い動作説明と、一工程一つの注意点を表示する。「2枚」「奥の1枚」「手前の1枚」を強調し、元の説明は「くわしく見る」に格納する。
- 裏の1枚を折る工程には、その場で裏側を確認できるボタンを付ける。正面リセット・裏側表示では現在の紙を見やすい大きさに合わせる。
- スマートフォンでは動作説明と注意点を3Dの上にも表示し、再生開始時には3Dが見える位置へ移動する。
- 教材としてユーザーが明示的に開始した折りの動きは、prefers-reduced-motionでも省略しない。自動再生はせず、一時停止と手動スライダーで見る速さを選べる。

初版は「次へ」と見本クリックで途中の動きを飛ばす設計だった。ユーザーの指摘を受け、形の2枚比較を残して上記の連続再生へ修正した。変更はUIと再生制御のみで、紙の形状は不変。

## 検証

build成功。lintは既存の6警告のみ。

PCと375×812のスマートフォン表示で確認。横方向のあふれがなく、再生開始時に3Dと短い注意点が見える。完成したコップへの正面リセットも確認。今回の検査でブラウザーエラーなし。
ブラウザーで実際に完成記録を加算する最終ボタンは押していない。再生と確認の分離は状態テストで検査した。
実物を折りながらの親子による利用確認は未実施。全作品へ展開する前に、読む量・手元と画面の往復・迷う工程を確認する。
