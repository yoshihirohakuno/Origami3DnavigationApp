## 2. 進行中の作業: かめ(turtle)の新規追加

**折り図の読みまで終わっていて、コードはまだ書いていない。** 続きはここから。

- 見本: https://www.origami-club.com/easy/animal/turtle/zu.html (全5パネル)
- 取得済み: `node tools/zu-measure.mjs fetch turtle` → `tools/.zu/turtle.{png,bmp}`
- 工程の読み(紙は [-1,1] の正方形、白い面を上にして始める):
  - ❶ 対角線2本の折り目をつけて戻す(アプリでは目印として使う方だけ折る方針で可)
  - ❷ **「\」対角線**(TL(-1,1)-BR(1,-1))で半分。右上の角を左下へ重ねる。
    折り返した裏(緑)が出る → 三角 TL(-1,1) / BR(1,-1) / BL(-1,-1)、直角は BL
  - ❸ もう半分。**「/」対角線**(BL(-1,-1)-中心(0,0))で、TL の角を BR へ重ねる
    → 三角 **(-1,-1) / (0,0) / (1,-1)**(直角が上の (0,0)、底辺が下)
  - ❹ **てんせんで かぶせおり**(outside-reverse)。左の先(-1,-1)を包んで頭にする
  - ❺ 目と甲羅を描いてできあがり(折りではない)
- パネル❹の実測(途中):
  - 底辺は px 307〜492.6(=2単位、**1単位 ≈ 92.8px**)、頂点は px (420,359)
  - かぶせ折りの破線は左の先から右上へ。**この破線の両端を実測するのが次の一手**
    (`node tools/zu-measure.mjs outline tools/.zu/turtle.bmp 290 340 510 490 8` と
    `probe` で、底辺(y≈473)と左の斜辺のあいだを走る破線を拾う)
- 色: 折り図の緑を実測して `sheetColors: [{ front: <緑>, back: '#f6f2e8' }]`、
  白面スタートなので `faces: backSideUp(F.map(orient))`
- 実装上の注意:
  - かぶせ折りは `type: 'outside-reverse'` が使える(実例は `src/models/whale.ts`)。
    **くじらでのハマりどころ: 軸を縦にすると回転が水平面内になって立たない。
    軸は斜めに取る。**
  - ❷❸で4層になるので、頭は層ごとの残差角/複製頂点が要るかもしれない。
    まず単純に組んで `window.__origami` で層順を実測し、白がのぞくなら
    `CLAUDE.md` の「層順の作り方」に従って直す

## 4. 保留(手を出す前に読む)

`CLAUDE.md` の「保留中の課題」に実測値つきで残してある。

- **さかな2**(easy/sea/fish2): ❺のパネルの輪郭が❹の結果と合わない。

## 5. 作業のやり方(最低限)

```bash
npx tsc -b && npm run dev            # 型 → 起動
node tools/zu-measure.mjs fetch <名> # 折り図の取得(画像名は zu.html から)
```

- 画面の検証は `window.__origami.setT(t)` / `getPositions()` / `getModel()`。
  **「角が○○に来る」という見本の目印は必ず数値で確認する。**
- 完成形の縦横比を折り図の完成図(`zu-measure.mjs bbox`)と比べる。
- 新しい作品を足したら `src/App.tsx` の MODELS と `src/catalog.ts` の CATEGORY_OF、
  `CLAUDE.md` の作品項目、`docs/verify-models.md` の表を更新する。
