どちらも「上の1枚だけ折る」または「先の工程で折った層をまたいで折る」ため、
**折り線を層ごとに鏡映して展開図へ埋める**作業(ヨット・くじらと同じ手法)が要る。

- **おむすび(easy/food/riceball、全6パネル)**: 紙はひし形(角 (0,±1)(±1,0))、
  白い面を上に始める(表=のりの灰、裏=白)。
  ❶たてよこの折り目(縦は使わないので省略可)→ ❷下の角を **y=-0.55** で折り上げる
  (実測: ❷の破線 -0.549 / ❸の灰色の三角の底辺 -0.553。角の先は y=-0.10 に来る)→
  ❸**まんなかの折り目 y=0** で下半分を手前へ折り上げる(下半分は❷で短くなっているので
  上半分を全部は覆わず、**上が白・下が灰**の三角になる = 折り図❹と一致)→
  ❹頂点 (0,1) から底辺の **(±0.62,0)** への線で下の両角をうしろへ(角は (±0.45,-0.34)
  まで回って底辺の下へ出る)→ ❺上の角を **y=0.80** でうしろへ + 下の両角を45°
  ((∓0.57,0.177)-(∓0.405,0))でうしろへ → ❻のりを描いてできあがり。
  **カテゴリは新設が要る**(たべもの)。`src/catalog.ts` の CATEGORIES に1行足すだけ。
- **ぶーつ(easy/clothes/boots、全6パネル)**: 紙は [-1,1] の正方形、白い面を上に始める
  (表=桃、裏=白)。❶右半分を左へ半分に折る(折り目は x=0 = 結果の右のふち)→
  ❷**上の1枚だけ**を、折った長方形の対角線 (-1,1)-(0,-1) で折る

## 4. 作業のやり方(最低限)

```bash
npx tsc -b && npm run dev            # 型 → 起動
node tools/zu-measure.mjs fetch <名> # 折り図の取得(画像名は zu.html から)
```

- 画面の検証は `window.__origami.setT(t)` / `getPositions()` / `getModel()`。
  **「角が○○に来る」という見本の目印は必ず数値で確認する。**
- 新しい作品/折りを足したら、**辺の長さの点検**(`CLAUDE.md` の同名の節)を必ず1回通す。
  折り線の向こう側の頂点を `moving` に入れ忘れる事故がこれで消える。
- 完成形の縦横比を折り図の完成図(`zu-measure.mjs bbox`)と比べる。
- 新しい作品を足したら `src/App.tsx` の MODELS と `src/catalog.ts` の CATEGORY_OF、
  `CLAUDE.md` の作品項目、`docs/verify-models.md` の表を更新する。
- 1作品 = 1コミット。何が見本と違ったか/どう直したかを書く。
