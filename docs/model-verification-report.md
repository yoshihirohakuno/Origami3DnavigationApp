## 2026-08-13

### cup コップ

- 見本: https://www.origami-club.com/fun/cup/zu.html
- 取得画像: `tools/.zu/cup.png` / `tools/.zu/cup.bmp`
- 工程の対応: 見本❶→app1、❷→app2、❸→app3、❹→app4、❺→app5、❻→app6
- 折り線の照合:
  - app1: 下の角を上の角へ合わせる半分折り。見本❶と一致。
  - app2/app3: 左右の角を反対側へ重ねる折り。モデルは `s = 2 - sqrt(2)`、`x = sqrt(2)-1`、`x = 3-2sqrt(2)` の厳密値で、角が反対側の斜め辺へ届く構成。見本❷❸と一致。
  - app4/app5: 手前の1枚、奥の1枚のフタを別々に折る。見本❹❺と一致。
  - app6: 口を開いて立体化。見本❻の完成図に対応。
- 完成形: 見本完成図の外接比は `line 183/137 = 1.336`、色面は `166/122 = 1.361`。アプリは立体投影のため単純な平面比では比較しないが、口が開いた台形コップとして一致。
- 判定: 一致。
- 対応: コード変更なし。既存実装のコメントどおり、原典に対応していることを確認。

### box 箱

- 見本: https://www.origami-club.com/traditional/box/zu.html
- 取得画像: `tools/.zu/box.png` / `tools/.zu/box.bmp`
- 工程の対応: 見本は7パネル。現行appは3工程で、対応不可。
- 折り線の照合:
  - 見本❶: 対角線の折りすじをつける。
  - 見本❷: 四すみを中心へ折る。4x4格子と対角線が現れる。
  - 見本❸❹: 左右を中心へ折って戻す。
  - 見本❺: 上下を中心へ折る。
  - 見本❻: 左右を開きながら箱へ立体化する。
  - 見本❼: 完成。
  - 現行app: 中央底と4壁を直接90度に立て、四隅の耳を畳む3工程トレイ。原典の四すみを中心へ折る工程、左右/上下の折りすじ、左右を開いて立体化する手順がない。
- 完成形: どちらも箱状だが、原典は「はこ1」の重ね箱型、現行appは簡易トレイ型。見た目以前に工程が別物。
- 判定: 相違あり(段階A: 折り方の相違)。
- 対応: 未修正。原典準拠にするには `src/models/box.ts` を4x4格子+対角線の展開図から作り直す必要がある。現行コメントに未一致を明記。
