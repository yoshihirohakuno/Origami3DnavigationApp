#### 実装スパイク

2026-08-13 に、4x4格子へ各小正方形の中心を追加し、全セルを4三角形へ分割する案を試した。
この分割では対角線、`x/y=±0.5`、`x±y=±1` がすべて面の辺になるため、折り線だけは原典に合う。

結果は不採用。四すみを中心へ折る工程と、最後に壁を90度へ起こす工程を共有頂点のまま連続させると、角の多層部分が互いに引っ張り合い、一覧プレビューの完成形が箱として読めない破綻形になった。

次に直す場合は、単純な共有4x4格子ではなく、角・壁まわりの層専用の複製頂点を先に設計すること。原典の「左右を開く」工程では、見た目は一体の角でも、エンジン上は壁側・三角耳側・内側へ入る層を分ける必要がある。

- 折り線の照合:

  - 見本❷: さらに半分の三角に折る。
  - 見本❸: 袋を開いて正方形につぶす。
  - 見本❹: 裏側も同様に袋を開く。
  - 見本❺❻: 向きを整え、正方基本形にする。
  - 現行app1〜8: 対角線2本と十字2本を、折って開く工程として先に全部作る。
  - 現行app9: 中線3本の連鎖回転で正方基本形へ畳む。
  - 現行app10〜11: 前後の花弁折り。
  - 現行app12〜15: 首・尾・頭の中割り折り、羽を開く。
- 完成形: 見本完成図の線外接比は `128/170 = 0.753`。現行appは立体投影のため同一視点での数値比較が必要だが、今回は工程差分が先に段階Aとして確定したため、完成形比の合否判定は保留。

- 対応: 未修正。原典準拠に直すには、三角2回から袋を開く正方基本形工程を、現行の折りすじ先行 collapse ではなく実工程として作り直す必要がある。
