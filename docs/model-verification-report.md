#### 実装スパイク

2026-08-13 に、4x4格子へ各小正方形の中心を追加し、全セルを4三角形へ分割する案を試した。
この分割では対角線、`x/y=±0.5`、`x±y=±1` がすべて面の辺になるため、折り線だけは原典に合う。

結果は不採用。四すみを中心へ折る工程と、最後に壁を90度へ起こす工程を共有頂点のまま連続させると、角の多層部分が互いに引っ張り合い、一覧プレビューの完成形が箱として読めない破綻形になった。

次に直す場合は、単純な共有4x4格子ではなく、角・壁まわりの層専用の複製頂点を先に設計すること。原典の「左右を開く」工程では、見た目は一体の角でも、エンジン上は壁側・三角耳側・内側へ入る層を分ける必要がある。
