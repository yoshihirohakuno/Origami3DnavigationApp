## カブトムシで残す課題

1. **背中中央の隙間と表裏**: 白い裏面が中央に見え、見本の閉じた背中とは一致していない。面を塗り直して隠さない。
2. **袋が開いていない**: 内側の八つの材料点が背骨の同じ位置に重なる。四枚のページ状の面を曲げても、実際の袋の口を開いたことにはならない。
3. **材料と層順**: 見本の袋、盾、角の根元を追跡し、連動する部分を特定する。三角形の角の根元と脚の姿勢は比較試作で、見本の全工程との一致は未確認。
4. **実物との照合**: 最終シルエット、層の通過、表裏を確認する。寸法・接続・接地のテスト成功だけで完成としない。

保持する試作: `/tools/beetle-study.html?stage=curved-pose`。144操作・1062頂点・1200面。詳細は [背中の比較記録](beetle-curved-back-2026-10-06.md)。今回はこの試作の形状を変更しない。

## バラで残す課題

1. **基礎のねじりと完成した花を区別**: 今回の16頂点・10面は、補助の対角線を持つ中央ねじりの検証単位。バラ全体の折り図を実装したものではない。
2. **折り図との材料対応**: 花用の格子、段折り、内外の花びらとなる材料の位置と層を確定する。検証単位の座標を、そのまま完成したバラの折り方として登録しない。
3. **花びらと底**: 花びらの立ち上げ、外側の巻き、底の折り込みと固定が未実装。紙の接続・寸法を保持した経路で追加する。
4. **描画と実物の照合**: ねじりの終端には循環する平らな重なりがあり、ブラウザーでは深度バッファの競合による縞が出る。全体へ一つの層順を付けて紙を離す方法で代用しない。領域ごとの重なりの処理と、開いた花の表裏・隠れる層を確認する。
5. **公開エンジンへの接続**: 今回の解析的な姿勢計算は開発用アダプターのみ。通常の回転データとして再生できると偽らず、後続の折りと細分点の追従まで設計してから公開へ移す。

開発用: `/tools/rose-study.html`。二つの連動動作に六つの停止位置があり、一度折って戻すだけの折り目付け工程は含まない。中央を開く後半は、重なりを保持してねじりを整える本体の動作。

詳細と検査範囲: [バラの中央ねじり](rose-twist-study-2026-10-07.md)。
