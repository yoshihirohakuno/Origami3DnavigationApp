## 発見した問題と修正

1. **髪の色が3Dで消える** (`boy.ts`、同じ薄い層を使う5作品も対象)。
   数値上の表裏判定とSVGは正しくても、1e-7の層間隔では深度バッファの精度が足りず、
   おとこのこの完成が全面白になった。既存の描画専用 `renderLayerSeparation` を
   boy / girl / father / moon / pancake / cicada に設定。物理座標・折り角度・層順は維持する。
2. **こーひーの取っ手が未完成** (`coffee.ts`)。
   旧4工程目で完成と表示したが、手前の三角を起こす動作は注意文だけだった。
   5工程目として追加。`flatSequence.exceptFold` で、2工程目に動き、4工程目で
   裏へ回っていない三角だけを選択する。胴は静止し、白い取っ手が右に出る。
3. **せみの胴を細くする最後の左右折りが欠落** (`cicada.ts`)。
   旧文書の「スワイベルが必要」は折り線の向きの読み違いだった。
   図の線は上が中心寄り、下が外寄りなので、通常の全層の山折りで処理できる。
   左右を8・9工程目に追加。4・5工程目も羽先を少し外へ出す折りにして、
   完成図の3本の下端を再現する。折り線の位置は参考図を基にした近似値。
4. **旧テストが不完全な完成形を固定していた** (`origami.test.mjs`)。
   こーひーの「右には紙がない」、せみの「完成幅が1」の期待値を置き換え、
   取っ手の白い面・胴の静止・左右の肩の収納・別々の羽先を検証する。
   描画専用間隔についても、各工程で元の表裏の面積比を保つ検証を6作品分追加。
